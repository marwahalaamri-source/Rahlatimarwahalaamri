# وثيقة هيكل «رحلتي» — المرجع الشامل للمشروع

> **الإصدار:** ١٫١ — يوليو ٢٠٢٦
> هذه الوثيقة هي المرجع المعتمد لكل ما يُبنى في الموقع.
> أي قسم جديد أو ميزة جديدة تُضاف إليها أولًا، ثم تُنفَّذ.
>
> **تحديث ١٫١:** استُبدل مفهوم «الأهداف المسطّحة بثماني تصنيفات» بفلسفة
> ثلاثية المستويات (عادات · أهداف · أحلام) + مفهوم «تركيز الأسبوع» العابر
> للأقسام (القسم ٢). صفحة `goals.html` المبنية سابقًا (تصميمًا فقط، بحفظ
> حقيقي) ستُعاد هيكلتها لتستوعب هذا التغيير في المرحلة التالية من التنفيذ.

---

## ١ — الرؤية

«رحلتي» نظامُ حياةٍ متكامل لمروه العامري — ليس موقعًا ولا تطبيق إنتاجية،
بل دفترُ حياةٍ فاخر يعيش معها كل يوم: يستقبلها بالتحية، يعرف أي يومٍ هو،
يعرض آخر خطواتها، ويكبر معها دون أن يُعاد بناؤه.

**المبادئ الثابتة:**
- فخامة وهدوء — لا ازدحام ولا ضجيج بصري
- عربي بالكامل (RTL) وأرقام عربية (٠١٢٣…) في كل مكان
- الشعار هو مركز الهوية ويُحترم كما هو
- الخلفية السينمائية (الجبال والشروق والطريق) تستمر خلف كل شيء
- الرئيسية مركز النظام: كل قسم يغذّيها ببياناته الحية
- بيانات مروه ملكها: محفوظة محليًا، قابلة للتصدير في أي لحظة
- **النمو بلا إعادة بناء:** هرمُ الطموح (عادات← أهداف← أحلام) وتركيزُ
  الأسبوع مفهومان جوهريان يُبنى فوقهما كل شيء — لا فوقهما لاحقًا
- **لا محتوى وهمي:** المخزن يبدأ فارغًا دائمًا (`buildEmptyStore`)؛ كل هدف
  وعادة وتدوينة وذكرى في الموقع بيانات مروه الحقيقية أو لا شيء — لا أمثلة
  عامة، وكل صفحة تعرض حالة فارغة أنيقة بدل المحتوى المفبرك

## ٢ — فلسفة الطموح الثلاثية + تركيز الأسبوع

هذا القرار المعماري الأهم في المشروع: النظام لا يُبنى حول «أهداف» فقط،
بل حول **ثلاثة مستويات متدرّجة** من الطموح، بالإضافة إلى **مفهوم عابر**
يربط الأسبوع كله بخيطٍ واحد.

### المستويات الثلاثة

| المستوى | الرمز | التعريف | أفق الزمن | آلية المتابعة |
|---|---|---|---|---|
| **عادات** | 🌱 | أفعالٌ صغيرة متكرّرة تبني نسختي المستقبلية | يومي/أسبوعي متكرّر بلا نهاية | سلسلة أيام (Streak) + تأشير يومي |
| **أهداف** | 🎯 | مشاريع متوسطة/طويلة المدى أعمل عليها فعليًا الآن | أسابيع إلى أشهر، بتاريخ مستهدف | نسبة تقدّم + معالم (Milestones) |
| **أحلام** | ✨ | طموحاتٌ كبرى قد تأخذ سنوات لتتحقق | سنوات، بلا ضغط تاريخ صارم | رؤية ووصف، لا شريط تقدّم صارم |

**العلاقة بينها هرمية اختيارية لا إلزامية:** حلمٌ كبير («زيارة اليابان»)
قد يُنتج هدفًا («صندوق ادخار السفر») قد يُنتج عادة («توفير مبلغ أسبوعيًا»)
— لكن يمكن أيضًا أن توجد عادة أو هدف مستقلّين دون أن ينتميا لحلمٍ بعينه.

**تصنيفات مجالات الحياة (مشتركة بين الثلاثة):**
شخصية · عملية · صحية · دينية · مالية · تعلّم · اجتماعية
(سبعة مجالات؛ لم تعد «أحلام» تصنيفًا — فقد صارت مستوًى قائمًا بذاته)

### واجهة واحدة، لا ثلاث صفحات منفصلة

الثلاثة تعيش في **صفحة واحدة موسّعة: «أهدافي»** (نفس الرابط
`sections/goals.html` المبني مسبقًا) بثلاثة تبويبات علوية:
**🌱 عادات · 🎯 أهداف · ✨ أحلام**

**سبب هذا الاختيار:**
- العلاقة بينها تدريجية («زووم» من الفعل اليومي إلى الحلم الكبير) —
  تجربة تصفّح واحدة تخدم هذا الشعور أفضل من التنقّل بين صفحات منفصلة
- شبكة فصول الرئيسية الثمانية المعتمدة تبقى كما هي دون تضخّم؛ بطاقة
  «أهدافي» الحيّة تلخّص المستويات الثلاثة معًا بدل الأهداف فقط
- كل مستوًى يحتفظ بتصميمه وحقوله الخاصة داخل تبويبه (لا قسر أحدها في
  قالب الآخر) — التبويب فقط هو المشترك

### تركيز الأسبوع 🎯 — المفهوم العابر للأقسام

كل يوم جمعة، أثناء التخطيط للأسبوع القادم، تختار مروه **بؤرة أو بؤرتين**
(حد أقصى ٢) لتكون محور الأسبوع القادم — مثل «تحسين إنجليزيتي»، «النوم
مبكرًا»، «القراءة يوميًا». هذا ليس عادة جديدة تُضاف كل يوم، بل **التزامٌ
واحد يُختار مرة كل جمعة** ثم يظهر تلقائيًا طوال الأسبوع في:

- **الرئيسية:** بطاقة/سطر يعرض تركيز الأسبوع الحالي ونسبة الالتزام حتى الآن
- **دفتري اليومي:** تذكيرٌ ثابت أعلى صفحة كل يوم + علامة سريعة
  «التزمتُ اليوم؟» لا تحتاج إعادة كتابة
- **التخطيط الأسبوعي:** يحلّ محل حقل «عادة الأسبوع» المفرد الذي بُني
  سابقًا (`week.habitTracker`) — يعرض عنصر/عنصري التركيز مع صف أيام
  السبت→الجمعة القابل للّمس، وفي **مراجعة نهاية الأسبوع** (الجمعة) يظهر
  **«نسبة الالتزام بتركيز الأسبوع»** المحسوبة تلقائيًا (أيام الالتزام
  المؤشّرة ÷ أيام الأسبوع المنقضية)

**يمكن ربط عنصر تركيز بعادة موجودة فعلًا** (من تبويب 🌱 عادات) فيتشارك
معها نفس تاريخ التأشير — أو يكون نصًّا حرًّا جديدًا بلا ربط، حسب الحاجة.

**أين يُختار:** كخطوة أساسية ضمن **روتين الجمعة** (`friday.html`، لم يُبنَ
بعد) — «اختيار تركيز الأسبوع القادم» ستُضاف كبند في قائمة الجمعة نفسها،
بجانب «التخطيط للأسبوع القادم» الموجود أصلًا.

- **الزجاج:** خلفية `rgba(16,26,48,.40)` + ضبابية 10–14px + حدود ذهبية
  شفافة + ظل `0 18px 50px` + خط ضوء علوي داخلي
- **الأزرار:** رئيسي ذهبي متدرّج بلمعة تنساب عند المرور؛ ثانوي شفاف بحدود رفيعة
- **الأشرطة:** ارتفاع 3px، تدرّج ذهبي، تمتلئ بحركة 1.4s عند الظهور
- **الحركة:** ظهور تدريجي (fade-up) هادئ، احترام `prefers-reduced-motion`
- **النجمة الرباعية ✦** من الشعار: عنصر الزخرفة الوحيد المسموح تكراره

## ٥ — طبقة البيانات `rahlati:v2`

مخزن واحد في `localStorage` تكتب فيه الأقسام وتقرأ منه الرئيسية:

```js
{
  journal:  [{ date, text, mood, gratitude }],

  week: {
    goal: "",                            // نيّة الأسبوع العامة (وصفية)
    quote: "",                           // اقتباس الأسبوع
    days: [                              // السبت → الجمعة — بطاقة قيادة يومية
      { name: "السبت", date: "",
        tasks: [{ t, done }],
        appointments: [{ time, text }],
        habits: [{ name, done }],        // عادات يومية عامة (منفصلة عن تركيز الأسبوع)
        notes: "" }, …
    ],
    shopping:   [{ item, done }],        // مقاضي الأسبوع
    priorities: ["", "", ""],            // أهم أولويات الأسبوع (٣ كحد أقصى)
    weeklyGoals: [                       // لقطة أهداف قصيرة للأسبوع (مستقلة عن تبويب 🎯 أهداف)
      { category: "شخصية", name: "", progress: 0 }, …
    ],
    review: {                            // مراجعة نهاية الأسبوع — تظهر الجمعة فقط
      worked: "", improve: "", learned: "",
      goalAchieved: null,                // true|false|null
      focusConsistencyPct: 0,            // نسبة الالتزام بتركيز الأسبوع — محسوبة تلقائيًا
      rating: 0                          // ٠–٥
    }
  },

  // تركيز الأسبوع — يُختار كل جمعة، ويظهر في الرئيسية + اليوميات + الأسبوعي
  weeklyFocus: {
    weekStart: "",                       // تاريخ السبت الذي يخصّه هذا التركيز
    items: [                             // عنصر أو عنصران كحد أقصى
      {
        text: "",                        // مثال: «تحسين إنجليزيتي»
        linkedHabitId: null,             // اختياري: معرّف عادة من habits[]
        checkedDates: []                 // تواريخ الأيام التي أُشّر فيها الالتزام
      }
    ],
    history: [                           // أرشيف الأسابيع السابقة لرصد الأنماط
      { weekStart, items: [{ text, consistencyPct }] }
    ]
  },

  // روتين الجمعة — قلب النظام: لحظة تدوير الأسبوع (`friday.html`)
  friday: {
    checklist: [{ name, done }],         // سورة الكهف، التخطيط، التنظيف، اختيار تركيز الأسبوع…
    reflection: "",                      // تأمّل في الأسبوع المنتهي
    gratitude: ["","",""],               // ثلاثة أشياء للامتنان
    spiritualPrep: "",                   // تحضير روحي وذهني للأسبوع القادم
    nextWeekGoal: "",                    // مرحلي — يُصبح week.goal عند التدوير
    nextWeekPriorities: ["","",""],      // مرحلي — يُصبح week.priorities عند التدوير
    nextWeekFocusItems: [{ text, linkedHabitId }], // مرحلي — يُصبح weeklyFocus.items عند التدوير
    scheduleNotes: "",                   // ملاحظات جدول الأسبوع القادم
    lastCompleted: ""                    // تاريخ آخر تدوير أُنجز فعليًا
  },
  thursday: {
    book: { title, image },              // كتاب الأسبوع وصورته
    checklist: [{ name, done }]          // روتين ليلة الخميس
  },

  // ————— هرم الطموح الثلاثي (صفحة أهدافي — ثلاثة تبويبات) —————

  habits: [{                             // 🌱 عادات — أفعال صغيرة متكرّرة
    id, name, category,                  // شخصية|عملية|صحية|دينية|مالية|تعلم|اجتماعية
    frequency,                           // يومية|أسبوعية
    active: true,
    streak: 0, longestStreak: 0,         // للأسبوعية: تُحسب بعدد الأسابيع المتتالية لا الأيام

    linkedDreamId: null                  // اختياري: تخدم حلمًا بعينه

    tasks: [{ t, done }],
    photos: [ dataURL ],

  dreams: [{                              // ✨ أحلام — طموحات كبرى بلا ضغط تاريخ

    relatedGoalIds: [],                   // الأهداف التي تخدم هذا الحلم

  }],

  projects: [{                            // 🚀 مشاريعي — لا علاقة لها بالوظيفة اليومية
    id, name,
    status,                              // مستقبلي|حالي|مكتمل
    progress, startDate, targetDate,
    why, notes,
    milestones: [{ name, done }],
    tasks: [{ t, done }],
    photos: [ dataURL ]
  }],

  // ————— صحتي: الوزن + التغذية + الرياضة + النوم + المكمّلات + العناية —————
  health: {
    weight: {
      startWeight,                       // ثابت لا يتغيّر — أساس حساب نسبة التقدّم
      current, target,                   // كجم
      log: [{ date, kg }]                // سجلّ الوزن عبر الوقت — يغذّي الرسم البياني
    },
    nutrition: {
      proteinGoalMin, proteinGoalMax,    // غرام يوميًا
      waterGoalL,                        // لتر يوميًا

    exercise: { log: [{ date, type, durationMin, painBefore, painAfter }] },
    sleep: { wakeGoal, log: [{ date, sleepTime, wakeTime, hours }] },
    supplements: [{ id, name, frequency, takenDates: [] }],  // يومية|أسبوعية
    care: { notes, photos: [ dataURL ] }
  },

  english:      { streak, todayTask },
  achievements: [{ name, when }],
  memories:     [{ caption, date, image }],
  settings:     { name, theme, reminder, lang },
  activity:     { journal, week, friday, habits, goals, dreams, health, … },

  // أرشيف الأسابيع المنتهية — يُبنى تلقائيًا عند كل تدوير أسبوعي
  weekHistory: [{ weekStart, review, weeklyGoals, focusItems: [{text, consistencyPct}] }]
}
```

### `health` — مرتبطة بالعادات والأهداف والتخطيط الأسبوعي، لا مصدر بيانات منفصل
`sections/health.html` لا تُنشئ نظام تتبّع مواز؛ كل تسجيل فيها يكتب أيضًا في
البيانات الحقيقية الموجودة أصلًا:
- **تسجيل وزن جديد** → يُحدَّث تلقائيًا تقدّم الهدف الحقيقي في `goals[]`
  («الوصول إلى وزني المستهدف») نسبةً ومُلاحظات، بالاعتماد على
  `weight.startWeight` الثابت (وليس أول قيد في `log[]`، الذي قد يُستبدل إن
  سُجِّل وزن آخر في نفس اليوم)
- **تسجيل تمرين** (بيلاتس/مشي/مرونة الورك/إطالة) → يؤشّر تلقائيًا العادة
  المطابقة في `habits[]` لهذا اليوم
- **حفظ تغذية اليوم** → إن بلغ الماء ١٫٥ لتر فأكثر أو البروتين ٩٠غ فأكثر،
  تُؤشَّر عادتا «شرب الماء» و«تناول البروتين» تلقائيًا
- **تسجيل نوم** → إن كان وقت الاستيقاظ ٥:٣٠ أو أبكر، تُؤشَّر عادة «النوم
  المبكر للاستيقاظ لصلاة الفجر»
- **تسجيل مكمّل يومي** → عند اكتمال كل المكمّلات اليومية لهذا اليوم، تُؤشَّر
  عادة «أخذ المكمّلات الغذائية»؛ Vitamin D (أسبوعي) يُزامَن مع عادة «فيتامين
  د» الأسبوعية
- **مرجع القراءة فقط:** استقرار عادة «العناية بالبشرة» هذا الأسبوع، وهدف
  «صحية» في `week.weeklyGoals` — كلاهما يُعرَض من مصدره الحقيقي دون نسخ

### تدوير الأسبوع — `rolloverWeek(store, force)`
اللحظة التي يبدأ فيها أسبوعٌ جديد فعليًا. مُعرَّضة عبر `window.RahlatiStore.rolloverWeek`:
- **`force=true`** — تُستدعى من زر «أنهيتُ الأسبوع… ابدئي القادم ✦» في `friday.html`.
  الأسبوع الجديد يبدأ دومًا اليوم التالي مباشرةً لبداية الأسبوع المنتهي
  (وليس `currentWeekStart()` مباشرةً، لأن الزر عادة يُضغط يوم الجمعة قبل أن
  يتغيّر التاريخ الحقيقي فعليًا للسبت التالي).
- **`force=false`** — فحص أمان تلقائي يُستدعى من `loadStore()` عند كل تحميل؛
  يُدوِّر فقط إذا تجاوز التاريخ الحقيقي أسبوع المتجر المحفوظ (تحسّبًا لتفويت
  جمعة كاملة دون ضغط الزر).

في الحالتين: يُؤرشف الأسبوع المنتهي في `weekHistory[]` و`weeklyFocus.history[]`،
تُبنى أيام الأسبوع الجديد (`week.days`) بتواريخ جديدة، وتُرقّى الحقول المرحلية
في `friday.nextWeek*` إلى `week.goal` / `week.priorities` / `weeklyFocus.items`
الحيّة — ثم تُصفَّر تلك الحقول المرحلية استعدادًا لروتين الجمعة القادم.
لأن الرئيسية واليوميات والتخطيط الأسبوعي تقرأ جميعًا من `weeklyFocus`/`week`
مباشرةً، ينعكس التدوير عليها تلقائيًا دون أي تعديل إضافي.

### قواعد الطبقة
- **الترقية الآمنة:** كل تغيير في المخطط يرفع رقم النسخة (`v2 → v3`)
  مع دالة ترحيل تنقل البيانات القديمة — لا تُفقد بيانات أبدًا. الانتقال
  لهرم الطموح الثلاثي يتطلّب: نقل أي هدف قديم بتصنيف `"أحلام"` إلى
  مصفوفة `dreams[]` جديدة، وحذف `week.habitTracker` بعد ترحيل قيمته
  (إن وُجدت) إلى أول عنصر في `weeklyFocus.items`
- **آخر نشاط:** أي كتابة من أي قسم تحدّث `activity[sectionId]` تلقائيًا
- **النسخ الاحتياطي:** قسم الإعدادات يتيح تصدير المخزن كاملًا كملف JSON
  واستيراده — بيانات مروه بيدها دائمًا
- **مستقبلًا (اختياري):** مزامنة سحابية تُبنى فوق نفس المخطط دون تغييره

## ٦ — البنية المعيارية (Modular & Scalable)

النظام مبني على **سجلّ أقسام مركزي** (`SECTIONS`) — كل قسم بطاقة تعريف واحدة:

```js
{
  id: "journal",             // معرّف ثابت (رابط الصفحة + مفتاح المخزن + مفتاح النشاط)
  title: "دفتري اليومي",
  icon: "…",                 // SVG خطّي رفيع ذهبي
  span: 3,                   // مساحة البطاقة في شبكة الرئيسية (2 أو 3)
  widget(store){ … }         // ما تعرضه بطاقته الحية على الرئيسية
}
```

**خطوات إضافة قسم جديد مستقبلًا (دون أي إعادة تصميم):**
1. عنصر جديد في `SECTIONS`
2. مفتاح جديد في المخزن + سطر في دالة الترحيل
3. صفحة `sections/الاسم.html` تستورد الهوية والمخزن المشتركَين

الشبكة، والتنقّل، وأسطر «آخر نشاط»، والبطاقة الحية — كلها تتولّد من السجل.
(مبدأ التبويبات داخل صفحة واحدة، المستخدَم في «أهدافي»، امتدادٌ لنفس
الفلسفة: تبويب جديد = بطاقة تعريف جديدة داخل الصفحة، لا صفحة كاملة.)

## ٧ — الرئيسية: لوحة حياة تعيش مع اليوم

### الثابت
- التحية الشخصية بالاسم + الشعار + «رحلتي» + سطر واحد + زرّان
- لمحة اليوم: التاريخ الميلادي والهجري، تركيز اليوم، تقدّم مهام اليوم
  (من خطة أسبوعها)، تقدّم الأسبوع، اقتباس اليوم
- **تركيز الأسبوع:** بطاقة/سطر يعرض بؤرة الأسبوع الحالية ونسبة الالتزام
- شبكة الفصول الثمانية ببياناتها الحية (بطاقة «أهدافي» تلخّص الثلاثة
  مستويات معًا: عدد العادات النشطة، أقرب هدف للإنجاز، وعدد الأحلام الحيّة)
- الاقتباس الكبير + طقوسي اليومية + التذييل

### المتغيّر تلقائيًا
| المتى | ماذا يحدث |
|---|---|
| حسب الساعة | التحية: صباح النور / نهارك سعيد / مساء الورد / ليلتك هادئة |
| كل يوم | اقتباس اليوم وكلمة الإنجليزية يتجدّدان |
| مكتبة الاقتباسات | `assets/js/quotes.js` — ٤٠٠+ اقتباس عربي هادئ؛ يُختار حسب التاريخ ويدور على المكتبة كلها (لا تكرار قبل أكثر من عام)، مع زرّ لتغييره يدويًا يُحفظ لبقية اليوم |
| **الخميس** | يظهر قسم «روتين الخميس — ليلة القراءة»: كتاب الأسبوع بصورته + قائمة الليلة |
| **الجمعة** | يظهر قسم «سورة الكهف وروتين الجمعة» بقائمة الجمعة وتقدّمها |
| مع كل استخدام | «آخر نشاط — اليوم/أمس/منذ ن أيام» في كل بطاقة |
| مع كل يوم من الأسبوع | تركيز الأسبوع الحالي ونسبة الالتزام تتحدّثان في الرئيسية واليوميات والأسبوعي معًا من نفس المصدر |

**للمعاينة في أي يوم:** `?preview=thu` أو `?preview=fri` في عنوان الصفحة.

## ٨ — الأقسام بالتفصيل

### ٠١ · دفتري اليومي `journal`
- **الصفحة:** تدوينة اليوم (نص حر) + مزاج اليوم + سطر امتنان،
  وأرشيف زمني أنيق لكل التدوينات مع بحث بسيط
- **جديد:** تذكيرٌ ثابت أعلى الصفحة بتركيز الأسبوع الحالي + علامة
  «التزمتُ اليوم؟» سريعة (تكتب في `weeklyFocus.items[].checkedDates`)
- **بطاقتها الحية:** حالة اليوم (كُتبت ✓ / لم تُكتب) + مقتطف آخر تدوينة
- **يفتح أوسمة:** أيام تدوين متواصلة (٧، ٣٠، ١٠٠…)
- **توسعة مستقبلية:** وسوم للتدوينات، «في مثل هذا اليوم»

### ٠٢ · التخطيط الأسبوعي `week`
- **الصفحة:** مركز قيادة الأسبوع كاملًا —
  ملخص الأسبوع (نسبة الإنجاز، المكتمل والمتبقي، نيّة الأسبوع، اقتباس الأسبوع)،
  شريط أيام من السبت إلى الجمعة (كل يوم بطاقة مهامها ومواعيدها وعاداتها
  وملاحظاتها ونسبة إنجازها)، أهم ٣ أولويات، قائمة المقاضي، أهداف الأسبوع
  حسب فئات قصيرة المدى بشريط تقدّم لكل منها، **تركيز الأسبوع** (عنصر أو
  عنصران) بصف أيام قابل للّمس بدل حقل العادة المفرد السابق، ومراجعة نهاية
  أسبوع تظهر الجمعة فقط (ما نجح، ما يحتاج تحسينًا، ماذا تعلّمتِ، هل تحقّق
  الهدف، **نسبة الالتزام بتركيز الأسبوع**، تقييم ٥ نجوم)
- **الحفظ حقيقي:** كل عنصر يُحفظ فورًا في `rahlati:v2.week`
- **بطاقتها الحية:** نسبة الأسبوع + نقاط الأيام + عدد المهام + نيّة الأسبوع
- **يغذّي أيضًا:** «تقدّم اليوم» في لمحة اليوم (مهام يوم اليوم من الخطة)
- **توسعة:** قوالب أسابيع جاهزة، ترحيل المهام غير المنجزة تلقائيًا

### ٠٣ · روتين الجمعة `friday` — قلب النظام، لا مجرد قائمة تحقّق (`sections/friday.html`)
- **الفلسفة:** كل جمعة يجب أن تُشعر بأنها إعادة ضبط حقيقية — لحظة إغلاق
  أسبوع وفتح آخر، لا مجرد خانات تُؤشَّر
- **الصفحة تضم ثمانية أجزاء:**
  ١) تأمّل في الأسبوع الذي مضى (`friday.reflection`)
  ٢) الامتنان — ثلاثة أشياء (`friday.gratitude`)
  ٣) مراجعة الأسبوع — ما نجح/ما يحتاج تحسينًا/ماذا تعلّمتِ/تقييم ٥ نجوم/هل
     تحقّق الهدف/نسبة الالتزام بتركيز الأسبوع — تشارك نفس `week.review` مع
     مراجعة الجمعة المختصرة في `week.html` (مصدر واحد، بابان لدخوله)
  ٤) مراجعة حيّة لعاداتها وأهدافها (عدد نشط، أطول سلسلة، أقرب هدف) — رابط
     مباشر لصفحة «أهدافي»
  ٥) تحضير روحي وذهني للأسبوع القادم (`friday.spiritualPrep`)
  ٦) **اختيار تركيز الأسبوع القادم** — بؤرة أو بؤرتان، قابلتان للربط بعادة
     من `habits[]` (`friday.nextWeekFocusItems`)
  ٧) أولويات الأسبوع القادم (`friday.nextWeekPriorities`)
  ٨) التخطيط للأسبوع القادم — الهدف الرئيسي وملاحظات الجدول
     (`friday.nextWeekGoal` / `friday.scheduleNotes`)
  + طقوس الجمعة التقليدية (سورة الكهف، تنظيف الغرفة…) كخانة تحقّق ثابتة
- **زر التدوير:** «أنهيتُ الأسبوع… ابدئي القادم ✦» يستدعي
  `RahlatiStore.rolloverWeek(store, true)` — يؤرشف الأسبوع المنتهي ويُرقّي
  كل الحقول المرحلية أعلاه إلى الأسبوع الجديد الحيّ فورًا (لا تُكتب البيانات
  مرتين، فقط تُنقَل)
- **الأثر التلقائي:** لأن الرئيسية واليوميات والتخطيط الأسبوعي تقرأ جميعًا
  `week`/`weeklyFocus` من نفس المصدر، تنعكس نتيجة روتين الجمعة عليها فورًا
  دون أي كود إضافي في تلك الصفحات
- **بطاقتها الحية:** «اليوم جمعة ✦» أو «بعد ن أيام» + تقدّم القائمة
- **على الرئيسية يوم الجمعة:** القسم الخاص بسورة الكهف + رابط لروتين الجمعة الكامل
- **توسعة:** استعراض `weekHistory[]` كأرشيف جُمَع سابقة وخواطرها

### روتين الخميس (يعيش داخل الرئيسية)
- كتاب الأسبوع (العنوان + الصورة — مساحة جاهزة تُملأ حين ترفعين صورة كتابك)
- قائمة الليلة: قراءة فصل، تجهيز قائمة الجمعة، تدوين خاطرة
- يُدار من قسم الإعدادات/الجمعة لاحقًا — مفتاحه `thursday`

### ٠٤ · أهدافي `goals` — هرم الطموح الرباعي، لا قائمة أهداف مسطّحة

صفحة واحدة بأربعة تبويبات (القسم ٢ يشرح فلسفة الثلاثي؛ «مشاريعي» أُضيف
لاحقًا بطلب مروه صراحةً كمستوًى رابع مستقلّ عن الأهداف):

**🌱 عادات** — أفعالٌ صغيرة متكرّرة، يومية أو أسبوعية
- كل عادة: مجال حياة (من السبعة)، تكرار (يومية/أسبوعية)، حالة نشطة،
  سلسلة حالية وأطول سلسلة (تُحسب بالأيام أو الأسابيع حسب التكرار)،
  شريط تأشير (١٤ يومًا للعادة اليومية، ٨ أسابيع للأسبوعية)
- عرض كبطاقات بسلسلة نار 🔥 بارزة، وتأشير اليوم بلمسة واحدة من الشبكة

**🎯 أهداف** — سبعة تصنيفات (بلا «أحلام»)
- نسبة تقدّم، تاريخ بداية ومستهدف، **«لماذا؟»** بصندوق مميّز، معالم
  تنفيذ كمسار خطوات متصل، مهام مرتبطة، ملاحظات، صور اختيارية
- لوحة ملخص: حلقة تقدّم عام، نشطة/مكتملة، أقرب هدف للإنجاز، آخر نشاط

**🚀 مشاريعي** — مشاريعي وأفكاري الشخصية، لا علاقة لها بالوظيفة
- نفس بنية الأهداف تقريبًا (تقدّم، معالم، مهام، صور) لكن بثلاث حالات فقط:
  مستقبلي/حالي/مكتمل — بلا تصنيف مجال حياة (لا تنتمي لمجالٍ واحد بالضرورة)
- مشروع «رحلتي» (هذا الموقع نفسه) موجودٌ هنا بتقدّمه الحقيقي المحسوب من
  خارطة الطريق §١٠ — تفصيلٌ يعكس أن النظام يتتبّع نفسه بصدق

**✨ أحلام** — طموحات كبرى
- كل حلم: مجال حياة، «لماذا؟»، رؤية وصفية حرّة، إطار زمني نصّي (لا تاريخ
  صارم)، حالة (حيّ/تحقّق/تغيّر)، أهداف مرتبطة تخدمه، لوحة صور/رؤية
- عرض أقرب لمعرض إلهام منه للوحة تتبّع — لا شريط تقدّم إلزامي

- **بطاقتها الحية على الرئيسية:** ملخص المستويات الأربعة معًا (عدد
  العادات النشطة، أقرب هدف للإنجاز بشريطه، عدد المشاريع الحالية، عدد
  الأحلام الحيّة)
- **يفتح أوسمة:** أول هدف مكتمل، أول عادة تبلغ ٣٠ يومًا متواصلة، تصنيف
  مكتمل بالكامل…
- **توسعة مستقبلية:** ربط هدف بمهام الأسبوع مباشرة (لا قائمة منفصلة)،
  ربط الأحلام بمشاريعها ومشاريعها بمهامها اليومية عبر `linkedDreamId`

### ٠٥ · رحلتي مع الإنجليزية `english`
- **الصفحة:** كلمة اليوم بمعناها ومثال، مهمة اليوم، سلسلة الأيام،
  قائمة الكلمات المحفوظة (مراجعة بسيطة)
- **بطاقتها الحية:** كلمة اليوم + السلسلة
- **توسعة:** اختبار مراجعة أسبوعي، ربط بهدف «٥٠٠ كلمة» أو عادة يومية

### ٠٦ · إنجازاتي `achievements`
- **الصفحة:** جدار الأوسمة — المفتوح مضيء والقادم صامت برمز غامض
- **تُفتح تلقائيًا من بقية الأقسام** (قواعد موثّقة في القسم ٩)
- **بطاقتها الحية:** أحدث وسام + العدد

### ٠٧ · ذكرياتي `memories`
- **الصفحة:** معرض صور بعناوين وتواريخ، إضافة ذكرى بصورة ولحظة
- **بطاقتها الحية:** آخر ذكرى بصورتها + العدد
- **توسعة:** «ذكرى من مثل هذا اليوم» على الرئيسية

### ٠٨ · الإعدادات `settings`
- **الصفحة:** الاسم، النمط، تذكير المساء، اللغة، كتاب الأسبوع (العنوان
  والصورة)، تصدير/استيراد البيانات (JSON)
- **بطاقتها الحية:** ملخص الإعدادات
