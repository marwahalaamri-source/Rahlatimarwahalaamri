# وثيقة هيكل «رحلتي» — المرجع الشامل للمشروع

> **الإصدار:** ١٫٠ — يوليو ٢٠٢٦
> هذه الوثيقة هي المرجع المعتمد لكل ما يُبنى في الموقع.
> أي قسم جديد أو ميزة جديدة تُضاف إليها أولًا، ثم تُنفَّذ.

---

## ١ — الرؤية

«رحلتي» نظامُ حياةٍ متكامل لمروه العامري — ليس موقعًا ولا تطبيق إنتاجية،
بل دفترُ حياةٍ فاخر يعيش معها كل يوم: يستقبلها بالتحية، يعرف أي يومٍ هو،
يعرض آخر خطواتها، ويكبر معها دون أن يُعاد بناؤه.

**المبادئ الثابتة:**
- فخامة وهدوء — لا ازدحام ولا ضجيج بصري
- عربي بالكامل (RTL) وأرقام عربية (٠١٢٣…) في كل مكان
- الشعار هو مركز الهوية ويُحترم كما هو
- الخلفية السينمائية (الجبال والشروق والطريق) تستمر خلف كل شيء
- الرئيسية مركز النظام: كل قسم يغذّيها ببياناته الحية
- بيانات مروه ملكها: محفوظة محليًا، قابلة للتصدير في أي لحظة

### الخطوط
- **Amiri** — العناوين، الأرقام الكبيرة، الاقتباسات (أناقة المجلات)
- **Almarai** (300/400/700) — النصوص والواجهات
- لا تباعد أحرف على النص العربي إطلاقًا (يكسر اتصال الحروف)

### المكوّنات المشتركة
- **الزجاج:** خلفية `rgba(16,26,48,.40)` + ضبابية 10–14px + حدود ذهبية
  شفافة + ظل `0 18px 50px` + خط ضوء علوي داخلي
- **الأزرار:** رئيسي ذهبي متدرّج بلمعة تنساب عند المرور؛ ثانوي شفاف بحدود رفيعة
- **الأشرطة:** ارتفاع 3px، تدرّج ذهبي، تمتلئ بحركة 1.4s عند الظهور
- **الحركة:** ظهور تدريجي (fade-up) هادئ، احترام `prefers-reduced-motion`
- **النجمة الرباعية ✦** من الشعار: عنصر الزخرفة الوحيد المسموح تكراره

## ٣ — البنية التقنية

- **HTML + CSS + JS خام** — بلا أدوات بناء، يعمل من أي استضافة ثابتة
  (GitHub Pages) ويفتح محليًا بنقرة واحدة
- **بنية الملفات المعتمدة عند بناء الأقسام:**

```
/
├── index.html            الرئيسية (لوحة الحياة)
├── sections/
│   ├── journal.html      دفتري اليومي
│   ├── week.html         التخطيط الأسبوعي
│   ├── friday.html       روتين الجمعة
│   ├── goals.html        أهدافي
│   ├── english.html      رحلتي مع الإنجليزية
│   ├── achievements.html إنجازاتي
│   ├── memories.html     ذكرياتي
│   └── settings.html     الإعدادات
├── assets/
│   ├── css/rahlati.css   الهوية المشتركة (تُستخرج من index.html)
│   ├── js/store.js       طبقة البيانات المشتركة
│   ├── js/sections.js    سجلّ الأقسام
│   ├── hero.jpg · logo.png · favicon.png
└── docs/STRUCTURE.md     هذه الوثيقة
```

- كل صفحة قسم تستورد نفس الهوية ونفس المخزن — فتبدو وتتصرف كجزءٍ واحد

## ٤ — طبقة البيانات `rahlati:v2`

مخزن واحد في `localStorage` تكتب فيه الأقسام وتقرأ منه الرئيسية:

```js
{
  journal:  [{ date, text, mood, gratitude }],
  week: {
    goal: "",                            // هدف الأسبوع
    days: [                              // السبت → الجمعة
      { name: "السبت", tasks: [{ t, done }] }, …
    ],
    shopping:   [{ item, done }],        // مقاضي الأسبوع
    priorities: ["", "", ""],            // أهم الأولويات (٣ كحد أقصى)
    review: ""                           // مراجعة نهاية الأسبوع
  },
  friday: {
    checklist: [{ name, done }],         // سورة الكهف، التخطيط، التنظيف…
    reflection: ""                       // مساحة التأمل والامتنان
  },
  thursday: {
    book: { title, image },              // كتاب الأسبوع وصورته
    checklist: [{ name, done }]          // روتين ليلة الخميس
  },
  goals: [{
    name, category,                      // روحانية|صحة|تعلم|شخصية|مالية|اجتماعية|أحلام
    progress,                            // ٠–١٠٠
    targetDate, notes, status,           // نشط|مكتمل|متوقف
    milestones: [{ name, done }]
  }],
  english:      { streak, todayTask },
  achievements: [{ name, when }],
  memories:     [{ caption, date, image }],
  settings:     { name, theme, reminder, lang },
  activity:     { journal, week, friday, goals, … }   // تاريخ آخر نشاط لكل قسم
}
```

### قواعد الطبقة
- **الترقية الآمنة:** كل تغيير في المخطط يرفع رقم النسخة (`v2 → v3`)
  مع دالة ترحيل تنقل البيانات القديمة — لا تُفقد بيانات أبدًا
- **آخر نشاط:** أي كتابة من أي قسم تحدّث `activity[sectionId]` تلقائيًا
- **النسخ الاحتياطي:** قسم الإعدادات يتيح تصدير المخزن كاملًا كملف JSON
  واستيراده — بيانات مروه بيدها دائمًا
- **مستقبلًا (اختياري):** مزامنة سحابية تُبنى فوق نفس المخطط دون تغييره

## ٥ — البنية المعيارية (Modular & Scalable)

النظام مبني على **سجلّ أقسام مركزي** (`SECTIONS`) — كل قسم بطاقة تعريف واحدة:

```js
{
  id: "journal",             // معرّف ثابت (رابط الصفحة + مفتاح المخزن + مفتاح النشاط)
  title: "دفتري اليومي",
  icon: "…",                 // SVG خطّي رفيع ذهبي
  span: 3,                   // مساحة البطاقة في شبكة الرئيسية (2 أو 3)
  widget(store){ … }         // ما تعرضه بطاقته الحية على الرئيسية
}
```

**خطوات إضافة قسم جديد مستقبلًا (دون أي إعادة تصميم):**
1. عنصر جديد في `SECTIONS`
2. مفتاح جديد في المخزن + سطر في دالة الترحيل
3. صفحة `sections/الاسم.html` تستورد الهوية والمخزن المشتركَين

الشبكة، والتنقّل، وأسطر «آخر نشاط»، والبطاقة الحية — كلها تتولّد من السجل.

## ٦ — الرئيسية: لوحة حياة تعيش مع اليوم

### الثابت
- التحية الشخصية بالاسم + الشعار + «رحلتي» + سطر واحد + زرّان
- لمحة اليوم: التاريخ الميلادي والهجري، تركيز اليوم، تقدّم مهام اليوم
  (من خطة أسبوعها)، تقدّم الأسبوع، اقتباس اليوم
- شبكة الفصول الثمانية ببياناتها الحية
- الاقتباس الكبير + طقوسي اليومية + التذييل

### المتغيّر تلقائيًا
| المتى | ماذا يحدث |
|---|---|
| حسب الساعة | التحية: صباح النور / نهارك سعيد / مساء الورد / ليلتك هادئة |
| كل يوم | اقتباس اليوم وكلمة الإنجليزية يتجدّدان |
| **الخميس** | يظهر قسم «روتين الخميس — ليلة القراءة»: كتاب الأسبوع بصورته + قائمة الليلة |
| **الجمعة** | يظهر قسم «سورة الكهف وروتين الجمعة» بقائمة الجمعة وتقدّمها |
| مع كل استخدام | «آخر نشاط — اليوم/أمس/منذ ن أيام» في كل بطاقة |

**للمعاينة في أي يوم:** `?preview=thu` أو `?preview=fri` في عنوان الصفحة.

## ٧ — الأقسام بالتفصيل

### ٠١ · دفتري اليومي `journal`
- **الصفحة:** تدوينة اليوم (نص حر) + مزاج اليوم + سطر امتنان،
  وأرشيف زمني أنيق لكل التدوينات مع بحث بسيط
- **بطاقتها الحية:** حالة اليوم (كُتبت ✓ / لم تُكتب) + مقتطف آخر تدوينة
- **يفتح أوسمة:** أيام تدوين متواصلة (٧، ٣٠، ١٠٠…)
- **توسعة مستقبلية:** وسوم للتدوينات، «في مثل هذا اليوم»

### ٠٢ · التخطيط الأسبوعي `week`
- **الصفحة:** هدف الأسبوع، خطة يومية من السبت إلى الجمعة (مهام قابلة
  للإنجاز)، قائمة المقاضي، أهم ٣ أولويات، مراجعة نهاية الأسبوع
- **بطاقتها الحية:** نسبة الأسبوع + نقاط الأيام + عدد المهام + هدف الأسبوع
- **يغذّي أيضًا:** «تقدّم اليوم» في لمحة اليوم (مهام يوم اليوم من الخطة)
- **توسعة:** قوالب أسابيع جاهزة، ترحيل المهام غير المنجزة تلقائيًا

### ٠٣ · روتين الجمعة `friday`
- **الصفحة:** قائمة الجمعة (سورة الكهف، التخطيط للأسبوع القادم، تنظيف
  الغرفة، مراجعة الأهداف، تأمل وامتنان) تتجدد كل جمعة + مساحة كتابة حرة
- **بطاقتها الحية:** «اليوم جمعة ✦» أو «بعد ن أيام» + تقدّم القائمة
- **على الرئيسية يوم الجمعة:** القسم الخاص بسورة الكهف
- **توسعة:** أرشيف جُمَع سابقة وخواطرها

### روتين الخميس (يعيش داخل الرئيسية)
- كتاب الأسبوع (العنوان + الصورة — مساحة جاهزة تُملأ حين ترفعين صورة كتابك)
- قائمة الليلة: قراءة فصل، تجهيز قائمة الجمعة، تدوين خاطرة
- يُدار من قسم الإعدادات/الجمعة لاحقًا — مفتاحه `thursday`

### ٠٤ · أهدافي `goals`
- **التصنيفات:** روحانية · صحة · تعلّم · شخصية · مالية · اجتماعية · أحلام
- **كل هدف:** نسبة تقدّم، تاريخ مستهدف، ملاحظات، معالم قابلة للإنجاز، حالة
  (نشط/مكتمل/متوقف)
- **الصفحة:** عرض حسب التصنيف، بطاقة لكل هدف بمعالمه، شاشة إضافة/تعديل أنيقة
- **بطاقتها الحية:** نشطة/مكتملة + أقرب هدف للاكتمال بشريطه
- **يفتح أوسمة:** أول هدف مكتمل، تصنيف مكتمل بالكامل…
- **توسعة:** ربط هدف بمهام الأسبوع (خطوة الأسبوع تخدم الهدف)

### ٠٥ · رحلتي مع الإنجليزية `english`
- **الصفحة:** كلمة اليوم بمعناها ومثال، مهمة اليوم، سلسلة الأيام،
  قائمة الكلمات المحفوظة (مراجعة بسيطة)
- **بطاقتها الحية:** كلمة اليوم + السلسلة
- **توسعة:** اختبار مراجعة أسبوعي، ربط بهدف «٥٠٠ كلمة»

### ٠٦ · إنجازاتي `achievements`
- **الصفحة:** جدار الأوسمة — المفتوح مضيء والقادم صامت برمز غامض
- **تُفتح تلقائيًا من بقية الأقسام** (قواعد موثّقة في القسم ٨)
- **بطاقتها الحية:** أحدث وسام + العدد

### ٠٧ · ذكرياتي `memories`
- **الصفحة:** معرض صور بعناوين وتواريخ، إضافة ذكرى بصورة ولحظة
- **بطاقتها الحية:** آخر ذكرى بصورتها + العدد
- **توسعة:** «ذكرى من مثل هذا اليوم» على الرئيسية

### ٠٨ · الإعدادات `settings`
- **الصفحة:** الاسم، النمط، تذكير المساء، اللغة، كتاب الأسبوع (العنوان
  والصورة)، تصدير/استيراد البيانات (JSON)
- **بطاقتها الحية:** ملخص الإعدادات

## ٨ — قواعد الأوسمة التلقائية (النسخة الأولى)

| الوسام | الشرط |
|---|---|
| أول تدوينة | أول حفظ في اليوميات |
| ٧ أيام تدوين متواصل | سلسلة يوميات = ٧ |
| أسبوع مكتمل | كل مهام أسبوعٍ منجزة |
| أول هدف مكتمل | هدف يبلغ ١٠٠٪ |
| جمعة كاملة ✦ | قائمة الجمعة كلها منجزة |
| ١٠٠ كلمة | كلمات الإنجليزية المحفوظة = ١٠٠ |
| أول ذكرى | أول صورة تُحفظ |

القائمة تكبر مع الوقت — كل وسام جديد يُضاف هنا أولًا.
