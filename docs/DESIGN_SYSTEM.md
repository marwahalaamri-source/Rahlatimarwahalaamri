# نظام تصميم «رحلتي» — المرجع النهائي المُلزم

> **هذه الوثيقة تُقفل شكل الموقع.** من الآن فصاعدًا: نضيف صفحات وميزات فقط،
> ولا نغيّر الهوية البصرية. أي صفحة جديدة تُبنى بنسخ اللبنات هنا حرفيًا —
> لا قيم ألوان جديدة، لا مكوّنات جديدة، لا تخطيط مختلف، إلا بتحديث هذه
> الوثيقة أولًا ثم تعميم التغيير على كل الصفحات دفعة واحدة.

---

## ٠ — المبدأ الجوهري

**رحلتي دفترٌ رقميّ شخصي، وليست لوحة تحكّم (Dashboard).**
كل صفحة يجب أن تُشعر مروه بأنها داخل نفس الدفتر الهادئ الفاخر التأمّلي —
لا نظام إدارة مهام، لا تطبيق إنتاجية. العنصر الذي يحمل هذه الهوية بصريًا
هو **الخلفية السينمائية الثابتة** (طريقٌ بين الجبال عند الشروق) التي تبقى
ظاهرة — هادئة وخفيفة — خلف كل بطاقة في كل صفحة، في الوضعين الداكن والفاتح.

**قاعدة صارمة:** لا تصل شفافية أي بطاقة (`--glass`) إلى درجة تُغرق الصورة
تمامًا. البطاقة زجاجٌ يكشف ما خلفه، لا سطحٌ مصمت.

---

## ١ — الألوان (CSS Variables)

كل صفحة تُعرّف **نفس الأسماء بالضبط** في `:root`، مع كتلة
`:root[data-theme="light"]` واحدة تعيد تعريف القيم الفاتحة. لا صفحة تُنشئ
نسخة مختلفة من هذا الجدول.

### الوضع الداكن (الافتراضي — `:root`)
```css
--navy-950:#0d1426;      /* خلفية الصفحة الصلبة (خلف الصورة، لا تظهر عمليًا) */
--navy-900:#101a30;
--navy-800:#16223d;
--gold:#c9b28c;          /* اللون الذهبي — ثابتٌ في الوضعين، لا يُكتب في كتلة light */
--gold-deep:#b3986e;     /* ثابتٌ في الوضعين */
--gold-soft:#e8dcc6;     /* نص ذهبي فاتح للعناوين الفرعية والاقتباسات */
--ivory:#f8f4ec;         /* لون النص الأساسي */
--glass:rgba(16,26,48,.42);      /* خلفية البطاقة (.panel) */
--hairline:rgba(201,178,140,.22); /* حدود البطاقة */
--ink-rgb:13,20,38;      /* ثلاثية RGB — لتراكيب rgba() المتكرّرة (تنقّل، تراكب الخلفية...) */
--paper-rgb:248,244,236; /* ثلاثية RGB — للنصوص الثانوية بشفافيات متفاوتة */
--glass-rgb:16,26,48;    /* ثلاثية RGB — لشارات وخلفيات العناصر الصغيرة */
--shadow-rgb:8,12,24;    /* ثلاثية RGB — لون ظل البطاقات */
--accent-navy-rgb:30,41,70; /* ثلاثية RGB — تدرّجات لوحات التمييز (روتين الجمعة، المراجعة) */
```

### الوضع الفاتح (`:root[data-theme="light"]`) — **القيم مُقفلة، لا تُعدَّل بلا تحديث هذه الوثيقة**
```css
--navy-950:#f7f4ee;      /* أوف-وايت دافئ */
--navy-900:#fffdf9;
--navy-800:#efe7d8;
--gold-soft:#93794c;     /* أغمق من نسخة الداكن — تباين كافٍ على خلفية فاتحة */
--ivory:#332c22;         /* نص رمادي/بنّي غامق دافئ، لا أسود صرف */
--glass:rgba(255,255,255,.5);   /* ⚠️ الحد الأقصى المسموح للشفافية — لا تُرفع فوق ٫٥٥ أبدًا */
--hairline:rgba(201,178,140,.35);
--ink-rgb:247,243,235;
--paper-rgb:51,44,34;
--glass-rgb:255,255,255;
--shadow-rgb:120,100,70; /* ظلّ دافئ خفيف، لا رمادي/أسود */
--accent-navy-rgb:230,214,186;
```

**قاعدة اللون الذهبي:** `--gold` و`--gold-deep` **لا تُكتبان إطلاقًا** داخل
كتلة `[data-theme="light"]` — تبقيان موروثتين من `:root` دون تغيير. هذا
مقصود: الهوية الذهبية للموقع واحدة في كل الأحوال.

**كيف تُستخدم ثلاثيات RGB:** أي قيمة `rgba(R,G,B, ألفا)` متكرّرة في التصميم
تُكتب `rgba(var(--xxx-rgb), ألفا)` بدل الأرقام الحرفية — هذا ما يسمح بتبديل
اللون كاملًا بين الوضعين من مكان واحد فقط.

## ٢ — الخلفية السينمائية (العنصر الأهم في الهوية)

كل صفحة — بلا استثناء — تحمل نفس ثلاث طبقات، بهذا الترتيب في أول `<body>`:

```html
<div class="bg" aria-hidden="true"><img src="[مسار]/assets/hero.jpg" alt=""></div>
<div class="bg-tint" aria-hidden="true"></div>
```

```css
.bg{position:fixed;inset:0;z-index:-3;overflow:hidden}
.bg img{width:100%;height:100%;object-fit:cover;object-position:center 62%;transform:scale(1.06)}
.bg-tint{
  position:fixed;inset:0;z-index:-2;pointer-events:none;
  background:linear-gradient(180deg, rgba(var(--ink-rgb),.55) 0%, rgba(var(--ink-rgb),.42) 30%, rgba(var(--ink-rgb),.6) 70%, rgba(var(--ink-rgb),.85) 100%);
}
```

- `position:fixed` — الصورة تبقى مثبّتة بالشاشة أثناء التمرير، لا تُقصّ ولا تختفي أبدًا خلف طول الصفحة
- الرئيسية فقط تستخدم تراكبًا أغنى (radial + linear) لأسباب الـHero الخاصة بها؛ باقي الصفحات تستخدم `linear-gradient` البسيط أعلاه — **لا تُضاف طبقات تعتيم إضافية** (مثل `.bg-dim`) خارج الرئيسية

## ٣ — الطباعة

- **العناوين والاقتباسات:** `"Amiri", serif` (`--font-display`) — دومًا `font-weight:700` للعناوين، `400`/مائل للاقتباسات
- **نص الواجهة:** `"Almarai", sans-serif` (`--font-body`) — `300` هو الوزن الافتراضي للنص العادي، `400` للتشديد الخفيف، `700` فقط للأزرار والأرقام البارزة
- **الأرقام:** عربية-هندية دومًا (`٠١٢٣...`) عبر `RahlatiStore.arabicNum()` — لا يظهر رقم إنجليزي في أي واجهة (باستثناء حقول `<input type="date/time/number">` الأصلية التي يتحكّم المتصفح بعرضها)
- **التاريخ:** ميلادي + هجري معًا حيث يُعرض التاريخ الكامل (مثال: نمط الرئيسية ودفتر اليوميات)

## ٤ — التخطيط والمكوّنات المعتمدة

### هيكل الصفحة (لكل صفحة قسم جديدة)
```
<nav> (نفس البنية أدناه)
<main class="wrap">
  <header class="day-head reveal in"> ترحيب + عنوان + اقتباس اليوم + saved-flag </header>
  <section class="panel health-stats section-gap reveal in"> ملخّص علوي (إن وُجد) </section>
  <section class="panel section-gap reveal in" style="padding:clamp(1.6rem,3vw,2.4rem)"> ... </section>
  ...
</main>
<footer> رحلتي — [اسم القسم] </footer>
<script src="[..]/assets/js/store.js"></script>
<script src="[..]/assets/js/quotes.js"></script>  <!-- إن احتاجت اقتباسًا -->
<script src="[..]/assets/js/theme.js"></script>
```

### شريط التنقّل (ثابت في كل الصفحات)
```html
<nav class="nav">
  <div class="nav-left">
    <a href="[..]/index.html" class="brand">
      <img src="[..]/assets/logo.png" alt="شعار رحلتي">
      <span>رحلتي</span>
    </a>
    <button class="theme-toggle" id="themeToggle" type="button" aria-label="تبديل المظهر">🌙</button>
  </div>
  <a href="[..]/index.html" class="nav-back">✦ الرئيسية</a>
</nav>
```
الرئيسية فقط تستبدل `.nav-back` بقائمة `.nav-links` + زر `.burger` للجوال —
لكن `.nav-left` (الشعار + زر تبديل المظهر) يبقى كما هو حرفيًا في كل صفحة.

### المكوّنات الجاهزة — لا تُعاد صياغتها، تُنسخ كما هي
| المكوّن | الاستخدام |
|---|---|
| `.panel` | البطاقة الزجاجية الأساسية لكل قسم |
| `.block-label` + `.icon` | عنوان صغير بخط فاصل ذهبي فوق كل كتلة محتوى |
| `.ruled` | textarea بخطوط دفتر للنصوص التأمّلية الطويلة |
| `.line-input` | حقل نص بخط سفلي بسيط (بلا صندوق) |
| `.num-input` / `.date-input` / `.time-input` / `.select-input` | حقول مضبوطة (خلفية داكنة شفافة، حدود ذهبية خفيفة) |
| `.cat-chip` / `.status-pill` | شرائح اختيار (تصنيف/حالة) — تُصبح تدرّج ذهبي عند التفعيل |
| `.stepper` | أزرار +/− دائرية لتعديل نسبة تقدّم |
| `.btn-add` | زرّ إجراء رئيسي — تدرّج ذهبي، نص داكن `#221d12` |
| `.why-box` | صندوق مميّز (حدود وخلفية ذهبية خفيفة) للحقول التأمّلية العميقة |
| `.photo-grid` / `.photo-thumb` / `.photo-add` | معرض صور قابل للإضافة (FileReader → base64) |
| `.saved-flag` + نمط autosave | مؤشر «✓ محفوظ تلقائيًا» يظهر لثانية بعد كل حفظ |
| `.reveal` / `.reveal.in` | ظهور تدريجي (opacity+translateY) — يبدأ الحالتان `reveal in` معًا (لا IntersectionObserver إضافي) |

### الأزرار والشارات — الألوان دومًا كما هي
تدرّج الذهب لكل الأزرار/الشارات المفعّلة: `linear-gradient(135deg,#e3cfa5 0%,#c9b28c 45%,#ab8f63 100%)`
مع نص `#221d12` (بنّي داكن ثابت، لا يتغيّر بين الوضعين — لأنه نصّ على خلفية
ذهبية دومًا، بصرف النظر عن وضع الصفحة).

## ٥ — الحركة (Motion)

- كل الانتقالات اللونية: `background-color .3s ease, background-image .3s ease, border-color .3s ease, box-shadow .3s ease, color .3s ease` عبر قاعدة عامة `*{transition:...}`
- العناصر ذات تأثيرات hover/transform الخاصة (البطاقات، الأزرار) تحتفظ بقواعدها الخاصة — لا تُلغى
- `@media (prefers-reduced-motion:reduce)` تُلغي كل الحركة فورًا — إلزامية في كل صفحة

## ٦ — تبديل المظهر (مرجع تقني)

- `assets/js/theme.js` وحده يدير المنطق (لا يُكرَّر في أي صفحة)
- كل `<head>` يبدأ **فورًا بعد `<meta charset>`** بسكربت مضمّن صغير يمنع
  وميض الوضع الخاطئ:
  ```html
  <script>(function(){try{if(localStorage.getItem("rahlati:theme")==="light")document.documentElement.setAttribute("data-theme","light");}catch(e){}})();</script>
  ```
- زرّ `#themeToggle` بأيقونة 🌙/☀️ فقط — لا نص

## ٧ — قاعدة صارمة: لا صفحة جديدة بدون هذه الوثيقة

قبل بدء أي صفحة جديدة (تشمل: العمل والمشاريع، الإحصائيات، وأي قسم لاحق):
1. يُنسخ `<head>` وهيكل `<nav>` والخلفية حرفيًا من صفحة موجودة (`friday.html`
   مثال جيد — الأحدث والأكثر اكتمالًا)
2. لا تُضاف قيمة لون جديدة إلا إذا كانت تدرّجًا ذهبيًا (مسموح دومًا) أو
   تستخدم متغيّرات هذه الوثيقة
3. أي تغيير في هذه القيم (مثال: رفع شفافية `--glass`) يُحدَّث هنا **أولًا**،
   ثم يُطبَّق على كل الصفحات الست دفعة واحدة — لا صفحة "مختلفة قليلًا"

## ٨ — سجلّ تصحيح (لماذا هذه الوثيقة وُجدت الآن)

في جولة إضافة الوضع الفاتح، قيمة `--glass` في الوضع الفاتح كُتبت
`rgba(255,255,255,.82)` (شفافية عالية جدًا) — هذا أخفى الخلفية السينمائية
شبه كليًا خلف البطاقات المتراصّة، فبدا الموقع "لوحة تحكّم بيضاء" بدل دفتر
رحلة. صُحِّح إلى `rgba(255,255,255,.5)` بعد فحص بصريّ حقيقي (سطح مكتب
وجوال، أعلى الصفحة وبعد التمرير) عبر كل الصفحات. **هذه الوثيقة هي الضمانة
ضد تكرار هذا الانحراف.**
